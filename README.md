# 🚨 FaberHealth Emergency Card

> A high-security, client-side offline medical emergency card and PWA featuring a cyber-medical interface, instant QR code generation, and full GDPR/EHDS data privacy compliance.

![FaberHealth Preview](https://img.shields.io/badge/Status-Active-brightgreen) ![GDPR](https://img.shields.io/badge/GDPR-Compliant-blue) ![License](https://img.shields.io/badge/License-MIT-yellow)

## ✨ Features
* **Zero-Knowledge Privacy:** All sensitive medical data stays securely inside the browser's `localStorage`. No backend database tracking.
* **Offline First:** Fully functional without an internet connection. Designed for first responders and emergency scenarios.
* **Instant QR Code Generation:** Generates an emergency-ready text QR code containing vital parameters.
* **Cyber-Medical UI:** Sleek dark-mode interface inspired by advanced health-tech dashboards.
* **EU Compliant:** Includes explicit user consent (Art. 6 & 9 GDPR) and an instant "Right to be Forgotten" (Art. 17 GDPR) self-destruct button.

## 🛠️ Tech Stack
* **HTML5 / CSS3** (Responsive Grid & Custom Glow UI)
* **Vanilla JavaScript** (Client-side logic)
* **QRCode.js** (Client-side QR generation)

## 🚀 Quick Start
1. Clone or download the repository.
2. Open `index.html` in any modern web browser or deploy it instantly via **GitHub Pages**.
